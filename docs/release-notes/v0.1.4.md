# UE Agent Backend v0.1.4

Date: 2026-05-16

This release adds the Web Evidence extension around Project QA while keeping the
backend local-first, offline-testable, and safe by default.

## Highlights

- Added Controlled Web Search as an optional supplemental evidence layer.
- Added a mock Web Search provider for deterministic offline tests and evals.
- Added an optional Brave provider for manual local smoke tests with an API key.
- Added Web Memory v1, a disabled-by-default local cache for high-quality web
  result metadata.
- Refactored Project QA retrieval into clearer pipeline, evidence normalizer,
  and source policy modules.
- Preserved all existing UE frontend response contracts.

## Evidence Priority

Project QA now resolves evidence in this order:

```text
Project Inventory / selected files
-> local KB / lexical or hybrid RAG
-> local markdown/code grep fallback
-> optional Web Memory
-> optional Controlled Web Search
-> source arbitration
-> retrieval quality gate
```

Controlled Web Search and Web Memory are supplemental. They do not overwrite the
knowledge base, do not become project facts, and do not bypass source
arbitration.

## Configuration

Default behavior remains offline:

```env
WEB_SEARCH_ENABLED=false
WEB_SEARCH_PROVIDER=disabled
WEB_MEMORY_ENABLED=false
```

Offline Web Search eval uses the mock provider. Real provider smoke is manual:

```env
WEB_SEARCH_ENABLED=true
WEB_SEARCH_PROVIDER=brave
WEB_SEARCH_API_KEY=your_key
WEB_SEARCH_ALLOWED_DOMAINS=dev.epicgames.com,docs.unrealengine.com,unrealengine.com
```

Run:

```powershell
.\.venv\Scripts\python.exe scripts\run_web_search_smoke.py --query "Unreal Engine Enhanced Input official docs"
```

## Verification

Validated locally before release:

```powershell
.\.venv\Scripts\python.exe -m ruff check app tests scripts
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts\run_web_search_eval.py --min-success-rate 1 --min-safety-pass-rate 1
.\.venv\Scripts\python.exe scripts\run_web_search_smoke.py --allow-disabled
```

Expected baseline:

- Unit/integration/contract/eval tests pass without live LLM, Qdrant, UE Editor,
  or network access.
- Web Search eval uses mock data only.
- Real provider smoke is opt-in and not part of default CI.

## UE Frontend Impact

No mandatory frontend changes.

Existing fields remain valid:

- `data.web_search`
- `debug_view.web_search`
- `data.web_memory`
- `debug_view.web_memory`
- `data.source_arbitration`
- `data.retrieval_quality_gate`

Optional frontend enhancements can display Web Search / Web Memory sections in
Debug View or add helpful/unhelpful feedback for Web Memory entries.
