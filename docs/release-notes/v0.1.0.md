# UE Agent Backend v0.1.0

Released: 2026-05-09

## Highlights

- Local FastAPI backend for Unreal Editor Agent workflows.
- Five primary workflow surfaces: Agent Chat / Project QA, Code Review, Code Generate, Logs Analyze, and Assets Inspect.
- Built-in Skill executors, declarative Tool Registry, ReAct Lite trace, and proposal-based editor operation bridge.
- Knowledge base retrieval works without embeddings through lexical/local grep search, with optional Embedding + Qdrant support.
- Project Inventory support for UE asset/code snapshots, including Blueprint metadata, Static Mesh settings, code files, and selected assets.
- Safe editor operations through proposal confirmation for asset rename, Static Mesh settings, Blueprint asset creation, and Blueprint graph automation v1.
- Observable execution through `user_view`, `debug_view`, task artifacts, metrics, eval reports, and runtime health checks.

## Quick Start

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m alembic upgrade head
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Minimum `.env`:

```env
OPENAI_API_KEY=your_key
OPENAI_BASE_URL=
CHAT_MODEL=gpt-4.1-mini
KB_SOURCE_PATHS=./knowledge
EMBEDDING_ENABLED=false
RAG_MODE=hybrid
RAG_FALLBACK_MODE=lexical_only
```
